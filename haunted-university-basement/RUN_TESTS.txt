For my part of this assignment, I added 11 JUnit 5 test classes for movement,
rooms, traps, quests, equipment, unlocking rooms, and overall game behavior.

boundary values. I kept the original game implementation unchanged.

I included only my tests in this folder. Lauren's tests will be merged with mine
for the final group submission. I included the original application source so
my section can run as a complete Maven project.

WHAT I TESTED
- RoomTest: room properties, exits, items, monsters, locks, traps, null arguments,
  and collections that should not allow direct modification.
- TrapTest: trap properties and disarming behavior.
- TrapResolverTest: missing/disarmed traps, damage boundaries, one-time traps,
  and repeating traps.
- MovementEngineTest: movement in every direction, missing exits, locked rooms,
  and entering/reentering rooms containing traps.
- QuestTest: starting status, each objective, repeated objectives, and completing
  both objectives in either order.
- QuestTrackerTest: relevant/unrelated items and monsters, null inputs, and a
  living versus defeated Final Exam Phantom.
- InteractionEquipmentAndUnlockTest: equipping/replacing weapons and armor,
  invalid equipment, missing/wrong keys, and unlocking without consuming keys
  or moving the player.
- GameEngineTest: public game actions, win/loss conditions, quest completion,
  and lethal traps.
- DungeonFactoryTest: room connections, starting conditions, placed items and
  monsters, independent game instances, and a complete adventure.
- MoveResultTest: returned success, message, trap status, and damage values.
- MainTest: the exact sample output and restoring System.out after the test.

HOW I CAN RUN MY TESTS IN ECLIPSE
1. I will use JDK 21 and extract this project into a separate folder.
2. I can import it through File > Import > Maven > Existing Maven Projects,
   select the folder containing pom.xml, and click Finish.
3. If the dependencies are unresolved, I can use Maven > Update Project.
4. I can right-click src/test/java and choose Run As > JUnit Test.
5. I expect 138 passing invocations for my suite. Parameterized inputs count
   as separate invocations.

I will keep JUnit's default sequential execution because MainTest temporarily
captures System.out and restores it in a finally block.

HOW I CAN RUN MY TESTS WITH MAVEN
With Maven and JDK 21 installed, I can open a terminal in the folder containing
pom.xml and run:

    mvn clean test

This runs the tests and generates target/site/jacoco/index.html.
Then I can run mutation testing with:

    mvn org.pitest:pitest-maven:mutationCoverage

The mutation output is in target/pit-reports/, including index.html,
mutations.csv, and mutations.xml. I kept all production classes included.
Internet access is needed for the first dependency download.
